# ANDIJON 3D CITY

## Talablar
- Node.js 20 yoki undan yangi
- Supabase loyihasi

## Ishga tushirish
1. Supabase loyihasi yarating.
2. Supabase SQL Editor oynasida `supabase/schema.sql` faylini to'liq ishga tushiring.
3. `.env.example` faylidan nusxa olib `.env.local` nomlang.
4. `.env.local` ichiga Supabase Project URL va anon/publishable key qiymatlarini kiriting.
5. Terminalda quyidagilarni bajaring:

```bash
npm install
npm run dev
```

6. Brauzerda `http://localhost:3000` manzilini oching.

## Muhim
- AC — faqat virtual o'yin tangasi, haqiqiy pul emas.
- Yangi foydalanuvchi uchun boshlang'ich balans 100,000 AC.
- Yer uchastkasi narxi 25,000 AC.
- Hech qachon `service_role` kalitini brauzerga yuboriladigan `.env` o'zgaruvchisiga qo'ymang.
- `.env.local` maxfiy ma'lumotlarni o'z ichiga oladi; uni hech kimga yubormang.

## Eslatma
Loyiha kodi birlashtirildi, ammo Supabase hisob ma'lumotlari kiritilmasdan va real muhitda sinovdan o'tkazilmasdan sayt to'liq ishga tayyor deb hisoblanmaydi.
